# Airwise — frontend demo

Cliente React/TypeScript/Vite para el catálogo, buscador y comparador demo existentes.

Consulte la [guía frontend](../docs/developer-guide/FRONTEND.md) para instalación, arranque de ambos procesos, proxy, scripts y limitaciones; el [manual de usuario](../docs/user-manual/README.md) explica el flujo. La evidencia ejecutada y lo pendiente están en [VALIDATION](../docs/developer-guide/VALIDATION.md).

Todos los vuelos y precios son sintéticos. No hay compra, reserva, cuentas ni conexión a proveedores reales. No incluya secretos en el cliente.
